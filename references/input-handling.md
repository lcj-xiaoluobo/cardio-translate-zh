# 多格式输入处理

## 通用原则

先确认内容是否完整可读，再开始翻译。只使用与当前输入格式相关的处理能力。不得根据缩略图、残缺 OCR 或不完整页面推断全文。

## 粘贴文本

- 保留段落、标题、图表编号、引文和脚注。
- 修复复制产生的多余换行、软连字符、乱码和 PDF 私有区连字。
- 合并行末断开的英文单词；保留术语本身需要的连字符。
- 常见编码异常包括 `ﬁ/ﬂ/ff/ffi/ffl` 连字，以及显示为方框或私有区字符的 `fi`、`fl`。
- 不删除看似重复但可能属于原文的句子，除非能确认是页眉页脚或复制重叠。

## 图片、截图和照片

- 以原始分辨率检查文字；必要时分区域放大、旋转或增强可读性。
- 先识别标题、正文、图注、标签、箭头、标尺、颜色图例和编号的空间关系。
- OCR 后对照原图复核医学术语、数字、上下标、希腊字母、单位及左右方位。
- 图像裁切导致内容缺失时，翻译可见内容并明确指出缺失边界。
- 不把箭头指向的结构名称与邻近标签串错。

## PDF

- 优先检查并提取文本层；仅对无文本层、乱码或局部扫描页执行 OCR。
- 识别单栏、双栏、多栏、跨页表格、边栏和页内阅读顺序。
- 去除重复页眉页脚，但保留页码、章节名以及与正文有关的边栏。
- 对公式、图表、异常字符和阅读顺序可疑页面进行页面渲染复核。
- 对混合型 PDF 分页选择文本提取或 OCR，避免对清晰文本层重复 OCR。
- 长 PDF 先建立页码与章节清单，再按自然章节连续处理。

## Word、演示文稿、电子表格及网页

- 使用对应格式的读取能力，优先保留标题、批注、文本框、表格、脚注和页面/幻灯片编号。
- 演示文稿按幻灯片及视觉阅读顺序处理，不把装饰文字混入正文。
- 电子表格保持单元格、表头、单位和脚注关系；不要仅按纯文本顺序翻译。
- HTML 或 EPUB 保留标题层级、图注、超链接文字和参考文献结构。
- 用户要求生成译后文件时，在不破坏原始文件的前提下另存新文件，并检查格式与内容完整性。

## OCR 高风险字符

重点复核：

- `I/l/1`、`O/0`、`S/5`。
- 小数点、负号、范围连接号、乘号和百分号。
- `μ/m`、`mg/μg`、`mm/mL`、`mV/V`。
- `α/β/γ/δ`、上下标、离子价态和导联名称。
- `LA/RA/LV/RV`、`L/R` 以及 anterior/posterior 等方位词。
- 人名、设备型号、药物剂量、P 值、置信区间和参考文献编号。

无法从上下文和原图双重确认时，保留不确定标记。
