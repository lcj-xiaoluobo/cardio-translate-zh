# 中国医学教材化翻译风格

## 基本风格

- 使用简体中文和中国大陆医学书面语。
- 术语先服从 A0 权威定名；句法、搭配、简称和段落组织再服从中国医学界既往阅读习惯。不得以“读起来熟悉”为由改回被 A0 更新的旧译名。
- 采用专业、简洁、自然、逻辑清晰的表达，避免翻译腔和口语化。
- 长句按逻辑关系适当拆分；短句可在不改变强调关系时合并。
- 优先使用明确主语；原文允许省略且中文更自然时可省略。
- 避免无信息量的“进行”“予以”“相关”“方面”等冗词。
- 不主动降低专业难度，不把规范医学术语改成模糊通俗说法。
- 以“像中国医学教材原生文字”为最终判断标准，不以逐词对应率衡量译文质量。

## 中国读者既往习惯

- 优先采用国内教材和临床写作中稳定的主谓顺序、方位表达、疾病简称与检查名称。
- 定义句常用“是指”“指”“称为”；结构描述常用“位于”“起自”“止于”“沿……走行”“汇入”“开口于”。
- 机制描述按“诱因或条件—机制—结果”组织；诊疗内容按“适应证—方法—结果或风险”组织。
- 首次出现写规范全称，后文可使用国内通行简称；简称不得与其他概念混淆。
- 不把国外指南常见的英文名词化表达原样移植为中文长名词串。
- 保留中国读者熟悉且不与 A0 冲突的表达，例如“冠心病”“心衰”等已定义后的规范简称。
- 遇到 A0 新定名与旧习惯不同，首次可写“A0 规范名（既往常用名：……）”；后文统一使用 A0 规范名。只有确有理解障碍时才提供旧名，不机械并列。

## 从语义稿到教材稿

完成准确的语义译稿后，必须再做一次中文改写：

1. 找出句子的医学主干：什么结构、位于哪里、与谁相邻、如何走行或由谁支撑。
2. 删除英文名词化结构，改用中文医学常见动词。
3. 将过长前置定语拆成“主句＋补充关系”。
4. 将同一结构的描述集中，避免主语在一句中反复跳转。
5. 检查连续三个以上“的”字；能够用动词、方位词或分句表达时予以改写。
6. 不牺牲方位、范围、条件和引文位置换取表面流畅。
7. 完成术语替换后重新调整搭配；权威术语进入句子后也必须符合中文语法，不能留下英文式修饰链。

允许的自然化改写包括：

- `is located above` → `位于……上方`
- `faces` → `朝向……`、`与……相对`
- `contains an artery` → `内有该动脉通过`
- `is supported by` → `由……支撑`
- `skirts posterolateral to ... before descending` → `先沿……后外侧走行，随后下行进入……`
- `the thin crest of ...` → 若无固定命名，可表达为 `薄而隆起的……`，避免生造“……顶部嵴”

## 逻辑和语气

- 区分 `may`、`might`、`can`、`is likely to`、`suggest`、`demonstrate` 等证据强度。
- 保留 `not`、`without`、`unless`、`except`、`only` 等否定和限定关系。
- 区分相关、预测、关联、因果、机制和假设，不互相替换。
- 区分推荐强度与事实陈述，如“应”“推荐”“可考虑”“不建议”。
- 保留比较对象、参照组、时间窗、适用人群和条件边界。

## 标点和数字

- 中文正文使用全角中文标点；英文缩写、公式和型号内部保留半角格式。
- 数值与单位遵循医学原文及国际单位习惯，不擅自换算或四舍五入。
- 保留范围、比值、上下标、置信区间和统计学符号。
- 百分数、剂量和时间间隔必须与修饰对象保持明确对应。

## 缩写、专名和引用

- 首次出现且未定义的专业缩写写出中文全称、英文全称和缩写；通行度极高且用户要求简洁时可酌情简化。
- 已在前文、图题或表头定义的缩写不重复展开。
- 研究名称、试验名称和量表名称通常保留英文缩写，并在首次出现时补充中文名称。
- 人名术语有稳定译名时使用稳定译名；无稳定译名时保留英文，必要时给出音译。
- 参考文献编号及引文位置与原文保持对应，不自行增加来源。

## 教材、图注和论文

- 教材正文强调定义准确、层次清楚和上下文连续。
- 图注先说明处理方式或观察视角，再描述解剖关系和要点，避免逐句机械断开。
- 论文保留目的、方法、结果和结论之间的文体差异。
- 指南和共识保留推荐级别、证据等级及规范措辞。
- 操作步骤使用清晰的动作顺序，不把描述性语句误译成强制指令。

## 解剖图注的组织顺序

长图注优先按下列逻辑分段；只使用原文实际包含的部分：

1. **观察方法**：切除、翻开或移除哪些结构，显示什么区域。
2. **关键观察**：用“注意：”引出需要特别识别的结构。
3. **空间关系**：说明结构的位置、连接、朝向和分离界面。
4. **血管或传导束走行**：先写起始或邻近关系，再写走行方向和终点。
5. **间隙及边界**：先给名称，再按后方、外侧、前上方、下方、内侧等统一顺序描述。
6. **支撑或组织构成**：集中放在结尾，避免与血管走行交叉叙述。

不要为了“结构层次”自行添加原文没有的解释性标题；使用自然分段即可。

## 常见僵硬表达的修正

| 避免机械表达 | 优先教材表达 |
|---|---|
| 某结构的后外侧处走行 | 沿某结构后外侧走行 |
| 开始从基底部脱离 | 开始与基底部分离 |
| 面对某结构 | 朝向某结构 / 与某结构相对 |
| 包含某血管 | 内有某血管通过 |
| 被某组织所支撑 | 由某组织支撑 |
| 某结构的薄嵴 | 薄而隆起的某结构（无固定命名时） |
| 位于……之上方 | 位于……上方 |
| 可被识别 | 可见 / 可辨认 |

## 译者说明

只在以下情况添加简短译者说明：

- 原文疑似排印或事实错误，且会影响理解。
- 存在两个均合理但临床含义不同的译法。
- OCR 缺损无法可靠恢复。

不得用译者说明扩写知识点或替作者纠正观点。
