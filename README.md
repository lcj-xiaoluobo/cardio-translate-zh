# Cardiovascular Medical Literature Chinese Translator

一个用于英文心血管医学文献中译的 Codex Skill。支持直接粘贴文本、图片、截图、扫描件、PDF、Word、演示文稿、电子表格、HTML、EPUB 等输入，采用中国大陆医学教材、指南和专业期刊常用术语，兼顾医学准确性、中文可读性和全文术语一致性。

## 适用范围

- 心血管医学教材、专著、指南、共识和学术论文
- 解剖学、病理生理学及临床操作说明
- 图片、图注、图内标签和复杂表格
- 单栏、双栏、多栏及扫描版 PDF
- 需要跨章节统一术语的长篇翻译项目

覆盖心律失常与电生理、冠状动脉介入、结构性心脏病、心力衰竭、心肌病、心血管影像、高血压、血脂与血栓、肺血管病、外周血管病、先天性心脏病、心血管外科及重症心脏病学等亚专业。

## 核心能力

- 将全国科学技术名词审定委员会《心血管病学名词（2025）》设为 A0 最高权限术语源，共收录 1434 条
- 规范稿未收录的术语再按项目术语、医学教材、国内指南及权威期刊逐级裁决
- 采用“医学语义还原→中国教材化改写”双阶段流程，兼顾准确性与中文自然度
- 对解剖图注按观察方法、空间关系、血管走行、间隙边界和支撑关系自然分段
- 对粘贴文本直接翻译，不添加不必要的前言和解释
- 识别并修复常见 OCR 连字、乱码、断词和跨栏错序
- 保留标题层级、图表编号、脚注、公式和参考文献序号
- 严格核对解剖方位、心腔侧别、数字、剂量、单位和统计量
- 支持纯中文、中英对照、图表翻译和译文审校模式
- 长文档按章节连续处理，并维护跨批次统一术语
- 对无法可靠辨认的内容明确标记，不根据上下文猜测

## 默认输出规则

- 默认只输出中文译文。
- 直接粘贴英文段落时，不写“以下是翻译”等前言。
- 缩写首次出现时通常采用“中文全称（英文全称，缩写）”。
- 人名或音译术语必要时采用“中文名（英文）”。
- 同一术语在同一项目中保持统一译法。
- 命中《心血管病学名词（2025）》时，采用其规范中文名，不被教材旧译或个人偏好覆盖。
- 允许在不增加医学事实的前提下拆句、合句、调整语序及改写被动句，避免逐词直译和生硬复合词。
- 仅在存在无法消除的 OCR、术语或原文歧义时增加“待核对项”。

## 质量标准

交付前检查：

- 无漏译、重复、错序或跨栏串行
- 医学术语和缩写全文一致
- 左右、前后、内外、近远端及心腔侧别准确
- 否定、条件、因果和证据强度未改变
- 数字、单位、剂量、统计量和上下标与原文一致
- 图表、脚注和参考文献编号对应正确
- 无残留 OCR 乱码或错误断词

## 使用说明

本仓库提供医学翻译工作流程、术语原则和质量控制规则。涉及出版、传播或大规模翻译第三方教材与论文时，请确认拥有相应的使用和翻译权限，并对最终医学术语进行专业复核。
